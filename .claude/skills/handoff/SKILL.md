# Context Handoff
Package the conversation into ONE clean block including: 1) the core goal, 2) every architectural/code decision and why, 3) current state (done, in progress, open issues), 4) exact file paths, functions and configs touched, 5) exact next steps. Do not drop technical details needed for code quality. Output only the block.
